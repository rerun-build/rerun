as_of 2026-11-15, dev 4296d1f

Source: code of `apps/ui` in a worktree of dev 4296d1f, read 2026-11-15. Paths are relative to the repository root. `verified` = the route file, the panel it renders and the code that leads to it were opened. `inference` = something was not opened; the row says what.

Reading depth, stated plainly: every `page.tsx` was opened at its first lines (imports, redirects, notFound calls, exports). Panel folders were checked by file list, by which files import them, and by test files. Panel bodies (chat, agent, foreman, dialogs, templates, rewind, brain, files, data) were NOT read line by line. Element names and message keys below come from code, not from a running app. Nothing was run.
