---
title: "Vault"
description: "Read the accounts, secrets and MCP servers your workspace keeps once for its coworkers."
---

The [Vault](/vault) is where your workspace keeps the accounts and keys its coworkers share: the apps you signed in to, the secrets you added, the MCP servers you registered, and the accounts of paid apps. These tools act with the access of the member who created the key, the same rules as the app: see [Who can do what](/vault#who-can-do-what).

<Warning>
  No value ever comes out of the Vault, and none goes in. The tools name an entry, say whether it works and who holds it. Adding an entry, signing in to it and typing its credentials happen in the Rerun app, never through the API.
</Warning>

## list_vault

Lists everything the Vault holds. Takes no parameter.

| Field | What it holds |
| --- | --- |
| `available` | `false` when the workspace's machine keeps no Vault yet. Its apps are then connected coworker by coworker, with `attach_connector`. |
| `entries` | The apps, MCP servers and secrets of the Vault |
| `paidAccounts` | The accounts of paid apps, like LinkedIn Pro and WhatsApp Pro |
| `coworkers` | The coworkers the key can see, with `canManage` when it may switch an entry on for them |
| `canAdd` | Whether the key's member may add to the Vault, in the app |
| `isAdmin` | Whether the key's member is an admin |

Each entry carries:

| Field | What it holds |
| --- | --- |
| `id` | The entry's id |
| `name` | The app, server or secret name |
| `kind` | `service` for an app of the library, `mcp` for an MCP server, `secret` for a secret |
| `slug` | The library slug, for an app |
| `account` | Which account it is: an email, a workspace name |
| `status` | `active`, `needs_auth` (waiting for a sign-in) or `needs_config` (waiting for a credential) |
| `sharedWithAll` | `true` when every coworker gets it, including the ones added later |
| `coworkers` | The coworkers that get it, `id` and `name` |
| `hiddenCoworkers` | How many more get it in Boxes the key cannot see |
| `canChange` | Whether the key's member may change it |

A paid account carries its `id`, `slug`, `name`, `account`, `status` (`connected`, `connecting`, `needs_reconnect` or `paused`), `coworkers` and `hiddenCoworkers`.
