<Note>
  On Rerun Cloud, the API follows the subscription: a workspace on its free trial or on a paid plan can create keys, and so can an expert sandbox. Once the subscription is over, every key of the workspace answers `401` until it is active again. [AppSumo Tier 1](/billing#appsumo-tiers) does not include the API. On a self-hosted install the API is always available.
</Note>
