Rerun Cloud is the same Rerun, hosted, plus what only a hosted service can offer: machines ready in seconds, included model credit, paid apps and paid data. The coworkers, the chat, the board and the Chief of Staff are the same code in both.

## Side by side

| | Open source | Rerun Cloud |
|---|---|---|
| Coworkers, chat, memory, skills, schedules | ✅ | ✅ |
| Services catalog, MCP, Composio | ✅ | ✅ |
| Template library | Your own templates | ✅ |
| A computer for each workspace | You host it, one command attaches it | Ready in 30 seconds |
| AI models | Your keys or subscriptions | Included credit, or your keys |
| LinkedIn Pro, WhatsApp Pro | | ✅ |
| Paid data (leads, SEO, social) | | ✅ |
| Email invitations | With your own Resend key | ✅ |
| Push notifications on the mobile app | | ✅ |
| Updates | Each release | Continuous |
| Support | Community | ✅ |

On your install there is no plan and no limit: unlimited coworkers, unlimited seats, every model tier.

## What is not in the open source build

Each item below, and what to do instead.

### Managed models with included credit

Rerun Cloud plans include model credit, so a coworker works with no key at all. On your install, the same Rerun models run on your `OPENROUTER_API_KEY`, with no credit counted, and you can connect your own provider keys or your Claude or ChatGPT plan. See [AI models](/self-host/models).

### LinkedIn Pro and WhatsApp Pro

Two paid apps of Rerun Cloud that act on a LinkedIn or WhatsApp account for a coworker. They are switched off here. For the same jobs, connect an MCP server for LinkedIn or WhatsApp, or the LinkedIn app through [Composio](/self-host/services#composio).

### Paid data

On Rerun Cloud, coworkers can buy data by the call: lead lists, SEO metrics, social profiles. Here, add those providers (Apollo, Semrush and the like) as services or MCP servers, with your own API keys.

### Email invitations

Rerun Cloud sends invitations for you. Your install sends them through your own [Resend](https://resend.com) account, once you set `RESEND_API_KEY` and `RESEND_FROM`: see [Email](/self-host/configuration#email). Without them, an invitation gives you its link to send yourself: see [Invitations](/self-host/administration#invitations). Sign-in codes go out through Supabase either way. Coworker notification emails are paused in this version, on Rerun Cloud too: notifications show in the app.

### The template library and the creator program

The template library is part of Rerun Cloud and does not ship with this build. There is no checkout, no payout and no creator program either. On your install, the library holds the templates you make: [create your own](/templates/create).

### The mobile app

The Rerun app for iPhone connects to your install too, with sign-in by email code and no push notifications: pushes go out through Rerun Cloud only. See [Mobile app](/self-host/mobile).

### Sign-in by phone, Google and Apple

Rerun Cloud also signs people in by SMS, Google and Apple. Here, sign-in is by email code. Google and Apple can be turned on with your own Supabase configuration: see [Sign-in](/self-host/configuration#sign-in).

### Support

Self-hosted installs get community support on GitHub. Read [Troubleshooting](/self-host/troubleshooting) first. An issue on GitHub with the logs and the steps to reproduce gets a look; one without is closed with a link to this guide.
